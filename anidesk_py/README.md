# AniDesk Python v0.2.0

AniDesk 当前主实现，使用 Python 3.13、PySide6 Widgets、httpx、sqlite3、pytest 和 PyInstaller。根目录的 Tauri v0.1.0 代码保留为功能和 `.anibackup v1` 兼容参照。

## 安装与运行

### 追更与备用日程

本季番剧顶部可按中文名或原名搜索当前所选季度，忽略大小写和首尾空格；搜索只筛选已载入目录，不调用 AniList，也不自动追更。海报与列表同时筛选，清空恢复完整目录；切换年份或季度会清空搜索并加载对应目录。

仅有 Bangumi 放送星期的追更作品会显示在周历对应星期，标记“时间待定 · Bangumi 星期参考”。该卡片不生成播出时间、不猜测集数、不发送通知，也不代表当前浏览周一定更新。点击可管理作品和播放地址；获得具体日程后优先显示具体日程，避免重复卡片。

点击追更先保存本地记录并刷新界面，封面和 AniList 日程在后台独立获取。网络失败不会取消追更。缺少时间的作品仍可在“全部追更”管理，周历上方也会提示待获取时间的作品。

日程优先采用手动时间和已有逐集日程；缺少未来逐集日程时使用 bangumi-data 放送规律生成标注“预计”的日程，再回退到 Bangumi 星期参考。预计日程不猜测集数、不触发系统通知；悬浮窗可展示预计时间，但不提供延后提醒。星期参考不会生成具体时间。

备用数据共享缓存于 `data/schedule-cache/`。启动先读取缓存，超过 24 小时后台刷新；运行期间随日程同步检查缓存。点击“同步日程”可强制刷新（连续请求有 5 分钟保护间隔）。刷新失败继续使用旧缓存，超过 7 天标记可能过期。

预计日程最多展示未来 35 天，遵守来源的完结时间。没有完结时间的规则保守限制为规则起点后 180 天，避免旧资料无限重复；超过此范围可使用手动时间。仅支持明确提供的单次、每日、每周、每月放送规律，不从首播日期猜测周播。

备用数据来源：[bangumi-data](https://github.com/bangumi-data/bangumi-data)，使用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可；本程序据其放送规律计算预计日期。另使用 [Bangumi 每日放送 API](https://github.com/bangumi/api)。预计日程表示作品首播放送规律，不等同于特定平台上线时间。

以下命令从源码仓库根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\anidesk_py\requirements.lock
.\.venv\Scripts\python.exe -m pip install --no-build-isolation -e "./anidesk_py[dev]"
.\.venv\Scripts\python.exe .\anidesk_py\run_anidesk.py
```

`requirements.lock` 固定开发及打包所需依赖；`[dev]` 安装包含测试和打包工具的本地项目。也可使用同一虚拟环境的 `python -m anidesk` 启动。

源码运行时，默认数据目录固定为 `anidesk_py/data/`，与 `run_anidesk.py` 相邻，不依赖当前工作目录。关闭主窗口会隐藏应用并继续驻留托盘，彻底结束请使用托盘菜单“退出”。

## 数据目录与旧版迁移

便携 exe 使用实际 `AniDesk.exe` 所在目录的 `data/`，不会将持久数据保存在 PyInstaller 临时解压目录。

```text
AniDesk.exe
data/
  anidesk.db
  covers/
  backups/
  logs/
  settings.ini
  appearance.json
  themes/backgrounds/
```

SQLite 运行时还可能产生 `anidesk.db-wal` 和 `anidesk.db-shm`。`settings.ini` 保存悬浮窗的屏幕、贴边方向与位置；`appearance.json` 保存外观，`themes/backgrounds/` 保存导入图片的本地副本；通用应用设置保存在数据库中。

默认数据目录尚无数据库时，程序优先检测旧 Python 数据目录 `%LOCALAPPDATA%/AniDesk`，再回退到旧 Tauri 数据目录。数据库使用 SQLite 快照复制，已有封面和备份会一并迁入，旧数据不删除。已有 `data/anidesk.db` 时直接使用，不重复迁移或覆盖。

移动或备份完整环境前先从托盘退出，随后一起复制 exe 和 `data/`；仅更换 exe 时保留原 `data/`。通过应用导出的 `.anibackup` 用于追更或仓库记录迁移，不应视为全部程序配置的完整副本。

## v0.1.8 页面排版与长篇感想

- 本季番剧默认海报卡片，支持侧边详情、卡片追更和切换列表；仓库按看完月份展示收藏卡片，搜索添加移至独立窗口。
- 仓库摘要入口打开独立长文页，默认最大化；F11 切换全屏，Esc 先退出全屏，Ctrl+S 或“保存感想”保存。纯文本长篇没有 500 字短评限制，分段、中文与表情完整写入 SQLite，并随仓库备份保存。
- 保存过程中继续输入不会被旧的保存结果覆盖；后台刷新仓库也不替换编辑器正文。返回、关闭和托盘退出时提示未保存修改；保存失败保留当前正文供重试。日期可单独修改保存。
- 通用设置分为提醒与桌面、同步与启动、本地备份；外观分为主题与背景、侧栏图片，均提供分组卡片与预览，窄窗口纵向排列。
- 悬浮窗采用 A 方案竖向日程卡，今天在前、昨天在后，显示封面、集数、时间及“计划时间已到/预计更新”。保留多地址、延后 10 分钟、拖动、贴边隐藏和边缘感应。
- 数据结构和便携数据位置兼容旧版；不重置数据，不向正式数据库加入示例作品。

## 每周放送与侧栏图片（延续 v0.1.7）

- 启动后进入“我的追更”，默认每周放送日历；上一周、下一周、本周切换只读取已缓存日程，不会伪造周期性更新时间。日期按本机时区计算，一周内同一作品的多集更新分别展示。
- 手动时间覆盖自动日程，只形成一条事件，未确定的集数不猜测。首播日期的星期推算继续在完整清单显示，不会直接生成日历事件。
- “全部追更”保留完整列表。点击卡片或列表作品后在右侧管理匹配、时间、播放地址、移入仓库和取消追更；主操作打开当前下拉框选中的地址。宽度不足时详情默认收起，可通过“作品详情”展开；周历允许横向滚动。
- “设置 → 外观 → 侧栏图片”提供三张随程序打包的原创插画和本地图片入口，支持位置、100–180% 缩放、顶部渐隐、关闭图片与恢复默认侧栏。侧栏图片下方不显示换图按钮。
- 侧栏配置与主窗口背景独立，旧版外观配置自动补充缺失字段。新环境默认使用夏日汽水配色；已有主题选择保留。上传图片保存本地副本，预览后点击“应用外观”才写入设置。
- 打包名称自动使用 `AniDesk-v<源码版本>.exe`，当前为 `AniDesk-v0.2.0.exe`。移动到旧版程序所在目录即可沿用同目录 `data/`，若使用开机自启，需保存通用设置以更新路径。

内置插画及完整生成提示词见 [resources/sidebar/README.md](src/anidesk/resources/sidebar/README.md)。

## 主题与背景（延续 v0.1.6）

- 内置樱花日常、星空放映室和夏日汽水，统一使用主题变量和 Qt 调色板，应用内弹窗及悬浮看板随主窗口换肤。
- “设置 → 外观”支持强调色、12/14/16 px 字号、装饰开关和背景图片；图片支持 PNG/JPG/WebP，最大 30 MB、4000 万像素，导入时缩放至最长边不超过 2560 px 并保存 PNG 副本。
- 背景亮度、柔化程度、面板不透明度即时预览。滑块预览合并处理，背景柔化只在图片或柔化程度改变时计算。
- 点击“应用外观”才原子写入配置；“撤销预览”返回上次保存状态，“恢复默认”先预览默认值。未保存的修改在重启后还原，导入图片的副本保留在本地。
- 配置损坏时使用默认主题并提示，背景丢失时回退主题底色。外观文件不包含在追更/仓库 `.anibackup` 中；完整迁移请复制整个 `data/`。
- 本季番剧提供海报与列表；已看仓库采用收藏册；我的追更提供日历和完整清单。

## 延续的 v0.1.5 行为

- 追更页的下一集从有效的未来播出日程中选取最早一项。手动时间仍优先；其时间已过时不再显示为下一集，清除覆盖后恢复使用自动日程。
- 本季番剧和我的追更增加每周播出星期。优先使用实际日程；只有首播日期时明确标记为推算，缺少信息时显示“未获取”。显示时间及星期按本机时区换算。
- 移除单作品提醒设置与全部提前分钟界面，系统通知从计划播出时间开始检查。旧提前分钟和单作品提醒开关字段仅为备份兼容保留，不再参与提醒逻辑。
- 保留全局系统通知、悬浮窗开关、手动时间覆盖和延后提醒。
- 悬浮窗继续汇总昨天和今天的日程，支持跨屏拖动、左/右贴边、鼠标边缘感应和托盘手动展开。
- 季度目录分页读取，封面分批后台缓存；已看仓库的看完日期和感想可直接编辑保存。

## 打包

从源码仓库根目录进入 `anidesk_py` 后构建：

```powershell
cd anidesk_py
..\.venv\Scripts\python.exe -m PyInstaller --noconfirm AniDesk.spec
```

输出为 **`anidesk_py/dist/AniDesk-v0.2.0.exe`**，使用 PyInstaller `onefile` 模式。分发时无需安装程序或附带 `_internal`；启动时会临时解压内置运行库，首次启动可能较慢。用户数据始终保存在实际 exe 相邻的 `data/`，移动使用环境时需要一起复制该目录。
